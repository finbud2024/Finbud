# Components Structure

## Organization

Components are organized by feature and functionality:

### `/Shared/`
Common reusable components used across multiple features:
- **UI/**: General UI components (buttons, modals, cards, etc.)
- **Charts/**: Chart and visualization components
- **Utils/**: Utility components

### Feature-specific folders:
- **Basic/**: Core navigation and layout components
- **ChatPage/**: Chat-related components
- **ChatBot/**: Chatbot UI components
- **FinAgentPage/**: FinAgent feature components
- **FinEdu/**: Education feature components
- **FinInvest/**: Investment feature components
- **FinManage/**: Financial management components
- **FinXpert/**: Expert analysis components
- **Home/**: Homepage components
- **MarketPage/**: Market data components
- **Notification/**: Notification components
- **PestlePage/**: PESTLE analysis components
- **RiskChat/**: Risk analysis and chat components
- **Stock/**: Stock-related components
- **SwotPage/**: SWOT analysis components
- **TutorialPage/**: Tutorial components

## Naming Convention
- Use PascalCase for component files: `ComponentName.vue`
- Use kebab-case for folders: `feature-name/`
